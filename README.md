# ICU Handover

Reads the ICCA handover report (exported as "XML file with report data") and shows each patient as a card for a phone, tablet or PC, with a bed map, ICU day, alerts and private personal notes.

**Use it:** https://worcestericu.com/handover (forwards to https://nickjcowley.github.io/icu-handover/)

- Runs entirely in the browser. The export is read on the device and never uploaded; only your own notes are kept, on that device, under a scrambled code, and they are deleted when the patient leaves the export or after 3 days.
- Works offline: use **Download for offline use** on the start page (or save `index.html`) and open it in Edge or Chrome, for example from the shared drive in Citrix. That copy can remember the handover folder and open the newest export automatically.
- Phones: install it as an app, tap **Worcester** or **Alexandra** to open the latest handover in OneDrive, copy all the text and switch back; it loads from the clipboard (Android automatically, iPhone with one tap) and clears the clipboard.
- Trust PCs: choose the M: drive export folder once and the newest export opens automatically, or drop an export file onto the page.
- The version label beside the title shows which version you have; copies show a notice when a newer version is published.
