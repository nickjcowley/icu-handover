ICU Handover

Reads the ICCA handover report (the XML export) and shows each patient as a card you can read on a phone, tablet or laptop. You can add your own private notes to each card, like scribbling on the paper sheet.

Use it on a trust PC or in Citrix
Download a copy, save it to the M: drive and open it in Edge. The copy works without the internet and can remember the handover folder.
Download for offline use
Handover folder

    Pick the folder the ICCA exports are saved in (for example the WRH Medical Handover XMLs folder on the M: drive). The page remembers it on this computer and opens the newest export for you next time.

    Drop the handover export here

    1. In ICCA, export the Handover report as XML file with report data.
    2. Drop the file here, or click Open export and choose it.
    3. Or copy it and paste it here: copy the file in File Explorer (or open it in Notepad and press Ctrl+A, Ctrl+C), then press Ctrl+V on this page. On a phone, copy it and tap Paste export.

    The export is read in this browser window and is not uploaded or stored. Only your own notes are kept on this device, filed under a scrambled code rather than the patient's name or number. Each note is deleted when its patient leaves the export, and in any case after 3 days. Notes are personal reminders, not clinical documentation: record decisions in ICCA.

    Layout check

    This shows how the file is laid out, with every name, number and word of clinical text replaced by x and 9, so it is safe to share. Only the headings (RFA:, Cons:, PMH: and so on) are kept. Copy it and send it to whoever is fixing the reader.
